# Registro de Execução do Código Java

## Ambiente

* Linguagem: Java
* JDK utilizado: Java 27
* Sistema operacional: Windows
* Arquivo executado: `src/Main.java`

## Compilação

O código foi compilado com sucesso utilizando:

```text
javac Main.java
```

## Execução

Após a compilação, o programa foi executado com:

```text
java Main
```

## Resultado

A execução apresentou a seguinte saída:

```text
Olá, meu nome é Rodrigo
Olá, sou um aluno.
```

## Conceitos demonstrados

O exemplo prático demonstra:

* Classe
* Atributo privado
* Encapsulamento
* Construtor
* Método
* Herança
* Sobrescrita de método (`@Override`)
* Polimorfismo

O código foi compilado e executado com sucesso, demonstrando na prática conceitos fundamentais de Programação Orientada a Objetos em Java estudados e consolidados no NotebookLM.
