# Prompts utilizados no NotebookLM

Este arquivo reúne os principais prompts utilizados durante o desenvolvimento do projeto **Miniguia de Estudos: Programação Orientada a Objetos com Java**.

---

## 1. Exploração inicial

```text
Explique o que é Programação Orientada a Objetos em Java e apresente seus principais conceitos.
```

### Objetivo

Obter uma visão inicial sobre o tema e identificar os principais conceitos que deveriam ser estudados.

---

## 2. Prompt estruturado

```text
Com base exclusivamente nas fontes deste notebook, explique os fundamentos da Programação Orientada a Objetos em Java.

Organize a resposta nos seguintes tópicos:
1. O que é Programação Orientada a Objetos;
2. O que é uma classe;
3. O que é um objeto;
4. O que são atributos;
5. O que são métodos;
6. O que é um construtor;
7. O que é encapsulamento;
8. O que é herança;
9. O que é uma interface;
10. O que é polimorfismo.

Para cada conceito:
- apresente uma definição simples;
- explique sua função em Java;
- apresente um pequeno exemplo prático;
- explique como ele se relaciona com os demais conceitos.

Ao final, apresente uma tabela comparando os conceitos e indique quais deles são diretamente relacionados entre si.

Utilize as fontes disponíveis no notebook como referência e indique as fontes utilizadas em cada parte da explicação.
```

### Objetivo

Refinar a solicitação inicial, delimitando os conceitos, o formato da resposta e a utilização das fontes.

---

## 3. Quiz de aprendizagem ativa

```text
Com base exclusivamente nas fontes deste notebook, crie um quiz para testar meu conhecimento sobre Programação Orientada a Objetos em Java.

Crie 10 perguntas, começando com conceitos básicos e aumentando gradualmente a dificuldade.

Regras:
- não apresente as respostas;
- misture perguntas conceituais e situações práticas;
- inclua questões sobre classes, objetos, atributos, métodos, construtores, encapsulamento, herança, interfaces e polimorfismo;
- apresente uma pergunta por vez;
- espere minha resposta antes de apresentar a próxima pergunta;
- após cada resposta minha, informe se está correta ou incorreta e explique o motivo utilizando as fontes do notebook.
```

### Objetivo

Utilizar aprendizagem ativa para verificar a compreensão dos conceitos estudados.

### Resultado

O quiz foi concluído com **10 questões respondidas corretamente**.

---

## 4. Prompt de consolidação

```text
Com base exclusivamente nas fontes deste notebook e considerando que já respondi a um quiz sobre Programação Orientada a Objetos em Java, faça uma revisão de consolidação.

Crie um resumo estruturado dos principais conceitos estudados:
- Programação Orientada a Objetos;
- classes;
- objetos;
- atributos;
- métodos;
- construtores;
- encapsulamento;
- herança;
- interfaces;
- polimorfismo.

Para cada conceito:
1. explique de forma simples e objetiva;
2. apresente um pequeno exemplo em Java;
3. explique sua relação com os demais conceitos;
4. destaque um erro comum que um estudante iniciante pode cometer.

Ao final, crie uma seção chamada "Como os conceitos se conectam", mostrando de forma progressiva como classe, objeto, atributos, métodos, encapsulamento, herança, interface e polimorfismo podem aparecer juntos em um programa Java.

Utilize apenas as fontes disponíveis neste notebook e indique as fontes utilizadas.
```

### Objetivo

Revisar os conceitos depois da atividade de aprendizagem ativa e reforçar as relações entre eles.

---

## 5. Prompt para criação do Miniguia

```text
Com base exclusivamente nas fontes deste notebook e em todo o conteúdo produzido durante os estudos, crie um "Miniguia de Estudos: Programação Orientada a Objetos com Java".

O material deve ser didático, organizado e adequado para alguém que está começando a estudar Java.

Estruture o conteúdo da seguinte forma:

1. Introdução à Programação Orientada a Objetos
2. Classes
3. Objetos
4. Atributos
5. Métodos
6. Construtores
7. Encapsulamento
8. Herança
9. Interfaces
10. Polimorfismo

Para cada tópico:
- apresente uma definição simples;
- explique sua finalidade em Java;
- apresente um pequeno exemplo de código;
- explique o exemplo;
- destaque um ponto importante para o estudante;
- indique a fonte utilizada.

Depois dos conceitos, inclua:

11. Como os conceitos se relacionam
- explique como os conceitos de POO podem ser utilizados juntos em um programa Java;
- apresente um exemplo integrado e simples.

12. Tabela de revisão
Crie uma tabela com:
- conceito;
- definição;
- finalidade;
- exemplo ou palavra-chave relacionada.

13. Erros comuns de iniciantes
Liste os principais erros conceituais que um estudante pode cometer ao estudar POO em Java.

14. Glossário
Crie um pequeno glossário com os principais termos técnicos utilizados no material.

15. Checklist de aprendizagem
Crie uma lista de verificação para que o estudante possa avaliar se já compreendeu cada conceito.

Use linguagem clara, objetiva e didática. Não acrescente informações que não possam ser fundamentadas pelas fontes disponíveis no notebook. Ao final, apresente as fontes utilizadas.
```

### Objetivo

Transformar o conteúdo estudado em um material final de consulta, organizado e reutilizável.

---

## Conclusão

Os prompts foram progressivamente refinados para passar de uma pergunta inicial ampla para atividades de estudo estruturadas, aprendizagem ativa, consolidação e produção do material final.

Esse processo demonstra a utilização da engenharia de prompts como parte da estratégia de aprendizagem com IA.
