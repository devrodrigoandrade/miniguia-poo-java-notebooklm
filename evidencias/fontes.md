# Fontes utilizadas

As fontes abaixo foram selecionadas para servir como base de conhecimento do notebook **POO com Java — Miniguia de Estudos**.

A seleção priorizou materiais da documentação oficial da Oracle relacionados aos fundamentos da Programação Orientada a Objetos em Java.

---

## 1. Object-Oriented Programming Concepts

**Fonte:** Oracle Java Tutorials

**Link:**
https://docs.oracle.com/javase/tutorial/java/concepts/

### Conteúdo utilizado

Material introdutório sobre Programação Orientada a Objetos e seus principais conceitos.

Foi utilizado como fonte de referência para a compreensão geral de POO.

---

## 2. Classes and Objects

**Fonte:** Oracle Java Tutorials

**Link:**
https://docs.oracle.com/javase/tutorial/java/javaOO/

Material relacionado a classes e objetos em Java.

## 3. What Is Inheritance?

**Fonte:** Oracle Java Tutorials

## 4. What Is an Interface?

## Critério de seleção

As fontes foram escolhidas por serem materiais oficiais da Oracle relacionados diretamente aos conceitos estudados.

Os materiais utilizados fazem parte dos **Java Tutorials** da Oracle e são materiais de referência mais antigos. O objetivo deste projeto foi estudar os fundamentos de Programação Orientada a Objetos utilizando essas fontes como base de conhecimento para as atividades realizadas no NotebookLM.
